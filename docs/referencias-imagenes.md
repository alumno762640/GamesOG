Las imágenes `Box - Front (World)` se guardan localmente para que el catálogo no dependa de hotlinks. LaunchBox clasifica este tipo como carátula frontal; su base la mantiene la comunidad. No se ha añadido una marca de consola al estuche conceptual de GamesOG.

La descarga reproducible de portadas está en `scripts/download-launchbox-covers.sh`. Los recursos complementarios se descargan con `scripts/download-launchbox-product-media.sh`: `Box - Spine` para el lomo cuando existe, `Clear Logo` para el USB básico y `Fanart - Background` para el diseño fijo del USB especial. Cuando LaunchBox no ofrece un spine para el registro, la maqueta compone el título en el lomo. Los dos scripts guardan una copia previa y restauran los ficheros si falla una descarga.

Las marcas, juegos e imágenes pertenecen a sus titulares y se muestran solo como referencias académicas; la base de LaunchBox es comunitaria.
